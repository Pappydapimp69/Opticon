# MIRAGE has moved

MIRAGE — the real-time 3D game about a survey party whose minds run out —
started here, on branch `claude/3d-party-hallucination-game-f31dj0`, and was
extracted into its own repository once it stood on its own:

**https://github.com/Pappydapimp69/mirage**

The reasoning for both the original in-repo build and the later extraction is
recorded in this repo's `docs/adr/0001-mirage-separate-game.md`, and in the new
repo's own `docs/adr/0001-extracted-from-opticon.md`.

Nothing under `mirage/` in this repo is current — this file is a pointer, not
a copy. Opticon itself (`game/`) is unaffected by the move.
